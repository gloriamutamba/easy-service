# Easy Service

Bienvenue sur Easy Service, une plateforme de mise en relation entre clients et prestataires de services.

## Structure

- `front/` — pages HTML, CSS et JavaScript
- `backend/app.py` — API Flask
- `backend/models/` — modèles (un fichier par entité)
- `backend/extensions.py` — SQLAlchemy et JWT

## Lancer

```bash
cd backend
.\.venv\Scripts\activate
python app.py
```

Ouvrir http://127.0.0.1:5000/

## Fonctionnalités
- Espace client
- Espace prestataire
- Gestion des demandes et devis
